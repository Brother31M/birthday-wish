# Interactive Birthday Website 🎂✨

An interactive and cute step-by-step birthday wish web page built using HTML, CSS, and Vanilla JavaScript.

## 🌟 Features
- **Interactive Steps:** Smooth progression through different celebration screens.
- **Lights On Animation:** Dark room transition into a bright celebration setup.
- **Cake Cutting:** Click/tap interaction to cut the birthday cake.
- **Secret Wishes:** Hidden message flip card.
- **Final Note:** Personalized birthday letter.
